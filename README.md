# ITP Practice

A free, plain-English study site for the TOEFL ITP: lessons and practice tests for Structure, Reading and Listening, a full mock test, and Standard and Harder levels.

Original practice material written for study use. TOEFL and TOEFL ITP are trademarks of ETS. This site is not affiliated with or endorsed by ETS. Score estimates are rough guides only.

## Run it

No build step. Open `index.html` in a browser, or publish with GitHub Pages (Settings, Pages, deploy from branch `main`, folder `/ (root)`).

## Files

- `index.html` page shell
- `css/style.css` styles
- `js/data.js` Structure lessons and Test 1
- `js/reading.js` Reading lessons, passages and Test 1
- `js/listening.js` Listening lessons and Test 1
- `js/hard.js` Harder tests for all three sections
- `js/app.js` pages, quiz engine, scoring and mock test

Listening audio uses the browser's built-in speech voices, so it sounds different on each device. Content has not been checked by a second teacher.
